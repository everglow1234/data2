## RISK MITIGATION FLOWCHART

### What If Things Go Wrong?

```
Risk 1: Insufficient BRSR Data
   │
   ├─ Mitigation 1: Use LinkedIn for gap-filling
   ├─ Mitigation 2: Flag companies with incomplete data
   └─ Mitigation 3: Focus on high-quality compliant companies only
       │
       └─> If still insufficient: Build "Basic Index" (3-tier only)


Risk 2: Companies Refuse Partnership
   │
   ├─ Mitigation 1: Start with CSR sponsors (already committed)
   ├─ Mitigation 2: Offer free benchmarking (value exchange)
   └─ Mitigation 3: Create FOMO through media ("50 joined, have you?")
       │
       └─> If still insufficient: Reduce partner target (20 instead of 50)


Risk 3: No Media Traction
   │
   ├─ Mitigation 1: Partner with ET, Mint for exclusive coverage
   ├─ Mitigation 2: Controversy: "Why are only 8% women in C-suite?"
   └─ Mitigation 3: Celebrity endorsement (female leaders)
       │
       └─> If still insufficient: Direct corporate outreach, skip media


Risk 4: Funding Dries Up
   │
   ├─ Mitigation 1: Make it self-sustaining (partners pay for benchmarking)
   ├─ Mitigation 2: Reduce team size, automate more
   └─ Mitigation 3: Seek recurring CSR commitments (3-year)
       │
       └─> If still insufficient: Reduce scope to 2 sectors only


Risk 5: SEBI Ignores Findings
   │
   ├─ Mitigation 1: Engage multiple ministries (not just SEBI)
   ├─ Mitigation 2: International pressure (ILO, UN Women citations)
   └─ Mitigation 3: ESG rating agencies adopt our metrics
       │
       └─> If still insufficient: Corporate voluntary adoption is still valuable
```
