**What's MISSING:**
- No tier breakdown (Junior, Middle, Senior, C-Suite)
- No age disaggregation
- No reason for attrition
- No return-to-work tracking
- No promotion rates by gender

### Why Companies Don't Voluntarily Disclose More

| Reason | Impact |
|--------|--------|
| **Legal risk** | Detailed data could expose pay gaps → lawsuits |
| **Reputation risk** | Poor numbers = bad press |
| **Competitive intelligence** | Don't want competitors to poach talent |
| **Effort** | HR systems not set up for granular reporting |
| **No incentive** | ESG ratings don't penalize missing data (yet) |

## THE FEASIBLE PATH: 3-TIER APPROACH

### TIER 1: BUILD WITH WHAT EXISTS (Year 1) ✅ START HERE

**Objective:** Create a "Basic Index" using only publicly available data

**Data Sources:**
1. BRSR reports (Top 1000 NSE companies)
2. Board composition (SEBI disclosures)
3. LinkedIn public profiles (validation)
4. PLFS for sectoral benchmarks

**What You Can Measure:**

| Metric | Data Source | Calculation |
|--------|-------------|-------------|
| **Board Gender Ratio** | SEBI disclosures | Women/Total directors |
| **KMP Gender Ratio** | BRSR (mandated) | Women in Key Managerial Personnel |
| **Overall Women %** | BRSR | Women/Total employees |
| **Pay Parity Proxy** | BRSR median wages | Female median / Male median |
| **Attrition Gap** | BRSR turnover | Female rate - Male rate |
| **Sector Benchmark** | PLFS | Compare company to industry average |

**The "Basic Pyramid":**

```
Limited to 3 Tiers (from BRSR):

┌─────────────────────────┐
│   BOARD                 │ → SEBI data
├─────────────────────────┤
│   KMP (Key Mgmt)        │ → BRSR mandated
├─────────────────────────┤
│   ALL OTHER EMPLOYEES   │ → BRSR mandated
└─────────────────────────┘

Not ideal, but REAL and ANNUAL.
```

**Year 1 Output:**
- "Equiverse Index v1.0 - Basic Edition"
- 500 companies ranked on 3-tier data
- Identify best/worst performers
- **Prove the concept; build credibility**

**Budget:** ₹15-20 lakhs (2-3 people, 6 months)
